# NRK STONES Website

A static HTML/CSS/JavaScript website inspired by the publicly visible NRK STONES page.

## Files
- index.html
- style.css
- script.js

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a public GitHub repository, upload these files, then:
Settings -> Pages -> Deploy from a branch -> main -> /root -> Save.

The contact form opens the visitor's email client using `mailto:`. For a real database/email form, connect a form service or backend.
